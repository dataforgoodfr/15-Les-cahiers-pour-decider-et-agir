# Contribuer

Ce projet est actif : l'équipe y travaille pendant la saison 2026-2027 de
Data For Good.

## Rejoindre le projet

Le meilleur moyen de contribuer est de rejoindre le Mattermost de Data For Good.
Nous cherchons des bénévoles en novembre.

Vous pouvez aussi contacter directement l'association
[Des cahiers pour décider et agir](https://www.decider-agir.fr/).

## Les données

Les cahiers contiennent des données sensibles. Avant toute contribution, lisez
[docs/donnees.md](docs/donnees.md).
